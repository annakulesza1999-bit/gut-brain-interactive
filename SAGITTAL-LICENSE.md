No changes to the illustration. The application adds a reference viewer only; it is not yet a graded hotspot map.

The interactive midsagittal teaching map uses the original unmodified illustration with new approximate gross-region overlays. Landmarks checked against Endotext, Functional Anatomy of the Hypothalamus and Pituitary, https://www.ncbi.nlm.nih.gov/books/NBK279126/. These overlays are pedagogical approximations, not a medical segmentation or diagnostic map. The original drawing does not separate the anterior and posterior pituitary; the anterior pituitary activity should retain its 3D atlas rather than use the approximate map.
