# University of Vienna-inspired teaching theme
Adapted from the Corporate Design Manual, Sommer 2025, pp. 10–16, 22–23, 29.
- Primary colors: university blue #0063A6 for slide headings/cover, web blue #005C99 for primary actions, blue-black #032138 for text, white backgrounds.
- Mint #2BA4A6, lilac #CA8ADB, yellow #FFDC4C for small accents; pale tints for data panels. Light green and orange-red reserved for semantic feedback. Never use white text on a secondary-color panel.
- UI uses Inter (web guidance). Slides use Source Sans 3, 600 headings and 400 body. Source Serif 4 used only as occasional accent. Source fonts are verified in CI and served locally with OFL notices.
- White content master with left alignment, generous margins and bullet spacing, small source footer. Optional blue cover master. Imported artwork stays unchanged. Sources are editable separately from private speaker notes.
- No university seal, wordmark, or official templates included; the manual restricts their use. This is a student teaching tool inspired by the documented design system, not an official university service.
- Existing saved decks use the new visual theme without data migration; source text must be separated into slideSources for the dedicated footer. Full browser regression and actual deck review still required.

Chart and activity palette: blue-black axes, white backgrounds, blue/mint/lilac/yellow derived accents and distinct dark participant lines. Anatomy itself preserves natural colors. The separate sagittal reference is a licensed medical illustration, not a clickable segmented 3D surface. Medial 3D orbit is limited to ±24 degrees azimuth and ±18 degrees elevation; full free rotation is retained for other views. The interactive sagittal region map still requires alignment against the exact illustration.
